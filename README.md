# Kestrel — brand assets (v4)

Side-view hovering kestrel, facing right: a slim smooth body path (head,
hooked beak, neck, torso, shoulder mass — 16 nodes) plus feather fans —
5 near-wing primaries, 4 tail feathers — all generated by
`tools/build_mark.py`. Previous versions are archived in `v1/`, `v2/`, `v3/`.
All artwork is original; no third-party assets are traced.

## Regenerating

```sh
cd brand/tools
python3 make_wordmark.py --font ../fonts/Outfit.ttf --out wordmark.json
python3 build_mark.py        # rewrites all SVGs + all_shapes.svg + corners.json
python3 check_smoothness.py  # must end with ALL OK
cd .. && ./export.sh         # PNGs, mono sets, templates, ICO, ICNS
```

`make_wordmark.py` takes the font path as an argument. `Outfit.ttf` is a
**variable font**; it is instantiated at weight **600 (SemiBold)** with
`fontTools.varLib.instancer`. Glyph outlines are extracted with
`fontTools` (`SVGPathPen`) and positioned with **HarfBuzz**
(`uharfbuzz`) shaping, so kerning and tracking (+3%) are real. The final
SVGs contain no `<text>`, no font references, and no embedded font.

Outfit is published under the **SIL Open Font License**; the license text
should be kept alongside the font file if redistributing.

## Construction notes (V4)

- Body: one closed path, 16 nodes, Catmull–Rom tangents; only deliberate
  corners are the beak tip and head/beak junction.
- Feathers: one `feather_outline()` generator (pivot, angle, length,
  width, curvature). Wing fan: 10° constant spacing; tail fan: 11°.
  Adjacent feather gaps measure 2.7–3.1% of mark height (target 2.5–3.5%).
- The optional far wing was dropped: its blades could not hold the
  required non-overlap gap behind the near wing.
- Eye: one shape — almond plus a short comma tail (the V2 malar slash is
  gone). A Steel Mid head-cap overlay is color-only.
- Favicon: simplified 3 wing + 3 tail feathers, flat fills, no gradients.

## Usage

- In-app UI / tinted glyphs: `kestrel-mark-mono.svg`.
- App icon: `kestrel-icon-color.svg` (mono variant for single-color contexts).
- Raster exports live in `export/`, including verified black/white mono
  PNG sets and `kestrel.icns` (written by the built-in fallback; `png2icns`
  and `iconutil` are not installed on this machine).
- The icon files have **transparent** backgrounds — do not place them on a
  colored tile.

## Don'ts

- Do not recolor outside the palette above.
- Do not stretch, rotate, or add effects (shadows, glows, outlines).
- Do not place Slate on dark backgrounds; use the on-dark lockup or Sand.
- Do not crop the margins; the bird needs its breathing room at small sizes.
